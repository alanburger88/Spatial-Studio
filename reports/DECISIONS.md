# Decision log

All decisions stay within the approved scope; none required sponsor approval. Dates are 2026-11-12.

| # | Decision | Why | Contract impact | Tests |
|---|---|---|---|---|
| D1 | **pnpm monorepo, TypeScript strict, packages consumed as source** (no per-package build) | Fast iteration; Vite and tsx consume TS directly; one `tsc --noEmit` typechecks everything | Matches TECH_STACK package boundaries (`layout` folded into `renderers`) | `pnpm typecheck` |
| D2 | **Resolver is a pure isomorphic package used by both browser and API** | Instant local re-resolution for spatial views; identical semantics for exports | Satisfies "pure resolver" invariant; runIds deterministic | 12 goldens incl. byte-identical `resultDigest` |
| D3 | **`result.diagnostics` keeps the oracle's exact shape; richer findings live in `findings`** | `verify_app.py` compares diagnostics by strict equality | Additive fields only | Golden + verify_app |
| D4 | **Paged composition = DOM measurement by an in-browser paginator running in headless Chromium**, then `page.pdf()` | ADR-004 permits explicit page grouping with measured heights; avoids Paged.js uncertainty | Page count is the composer's page tree; independently cross-checked by counting PDF page objects | AT-18/19, Page Stack `PDF verified N` |
| D5 | **Fixed elements that intersect the flow region shrink that page's flow region** (FIXED_FLOW_ADJUSTED warning) rather than text-wrapping | "Cannot silently overlap" with bounded POC complexity | Documented limitation | Composer diagnostics |
| D6 | **Document fonts use the Arial stack (Liberation Sans here); UI uses Inter** | Brand guide specifies Arial for documents; Inter OTF alternates produced unmapped PDF glyphs (amounts not extractable) | Improves PDF text fidelity | AT-24/28 text extraction |
| D7 | **Additive `showSection` targets are modelled as rule-driven Conditional Region nodes** (and materialised from content parts if not a node) | Keeps them visible/selectable in the editor and explodable | Seed node IDs preserved; selectedVariants still only lists Variant Sets (oracle parity) | Golden tests |
| D8 | **Conditional Region (C10) = ordered branches with typed inline conditions, exclusive or additive, optional fallback** | Gives C10 genuine behaviour distinct from C11 | Inline evaluations appear in the trace as `inline-condition` | Unit AT-07 model test + E2E |
| D9 | **Undo/redo = immutable snapshots (immer); every undo/redo is itself a new model version** | Monotonic modelVersion for optimistic concurrency; dirty = content digest ≠ saved digest | `PUT` with `If-Match` | API conflict test |
| D10 | **Exports from unsaved drafts**: the client posts the current model; the API validates it (schema + every rule) and records an immutable run | Hero path requires editing → exporting without forcing saves; still "compose from a recorded run" | Run table stores the exact request | AT-29 (draft compose), API tests |
| D11 | **`contentDigest` is content-addressed** (excludes model version counter and producer) | Reset increments versions; deterministic replay must compare content | Digest semantics documented | AT-36 identical digests |
| D12 | **Issued journey snapshots are write-once rows (sha256 of canonical manifest + HTML), verified on every read** | ADR-006 immutability, provable | `alreadyIssued`, `verified` flags | API test, AT-21 |
| D13 | **Member liability guard**: unconfirmed `patientResponsibilityCents` is rendered "Not determined — under review", excluded from money facts, and debt wording raises UNCONFIRMED_DEBT_LANGUAGE | EOB rule "never infer $300 owed" | New domain finding code | AT-29 |
| D14 | **Spanish copy is not pre-translated in the seed** | Golden `card-spanish-missing-mandatory-translation` requires the blocking error; fixing it = adding an approved translation in the content editor | Spanish personas show a real D02 defect until translated | AT-20 |
| D15 | **Offline assistant = deterministic grammar; live adapter = official `@anthropic-ai/sdk`, model `claude-opus-5-5`, effort `low`, server-side refusal fallback (`fallbacks: "default"`), tool output re-validated with zod** | Spec requires a working fallback; Claude is the supported provider in this codebase | No browser keys; any provider failure → offline | AT-30/31/32 (offline); live path unverified |
| D16 | **InfoSlips brand tokens applied (greens, slate scale, Inter UI / Arial documents); no logo artwork bundled** | Brand pack in this environment provided palette/typography only; brand rules forbid redrawing the logo | `--iss-logo-url` slot ready for the official asset | Visual review |
