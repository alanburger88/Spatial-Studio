# InfoSlips logo artwork

Official artwork supplied by InfoSlips. Use as supplied: do not redraw, recolour, stretch or add effects.
Keep clear space around the logo; minimum width 120 px for the full logo and 24 px for the icon.

| File | Artwork | Use on |
|---|---|---|
| `infoslips-logo-on-light.png` | Green mark, dark wordmark (575×136) | Light backgrounds |
| `infoslips-logo-on-dark.png` | Green mark, white wordmark (576×136) | Dark backgrounds |
| `infoslips-logo-white.png` | All white (576×136) | Green or photographic backgrounds (not used by the studio yet) |
| `infoslips-icon.png` | Icon only (140×135) | Tight spaces; also the browser tab icon (`public/favicon.png`) |

The studio renders these through `BrandLogo` in `src/ui/Brand.tsx`. Documents exported from the studio carry the
document issuer's brand kit, not this logo.
